# Architecture

The site is built so one change lands everywhere. Content, visual tokens and motion settings each have exactly one home.

## Folder map

```
src/
  config/motion.ts        Every tunable motion and interaction number
  styles/tokens.css       Design tokens for both themes (colour, type scale, radii, spacing, easing, z-index)
  styles/base.css         Reset, layout primitives, buttons, chips, reveal-on-scroll, theme wipe, cursor rules
  styles/prose.css        Lab write-up typography, tables and CLI blocks
  data/site.ts            All copy and facts: profile, nav, featured lab copy, process, credentials, experience, toolbox
  data/github.json        Build-time GitHub snapshot (generated)
  content/labs/*.md       One file per lab (generated by scripts/sync-labs.mjs)
  content.config.ts       Lab schema; the build fails if a lab file is missing a field
  assets/                 Topologies, slides, certificates, portrait (optimised by Astro at build)
  lib/labs.ts             Lab ordering used by every page
  lib/rehype-cli.mjs      Styles Cisco CLI prompts, top-level commands and comments; wraps wide tables
  scripts/core.ts         Shared GSAP, ScrollTrigger and Lenis instance, anchor scrolling, reveal observer
  scripts/theme.ts        Light and dark theme with the circular View Transition wipe
  scripts/sound.ts        Synthesised Web Audio ticks, clicks and whooshes, with an on/off setting
  layouts/Base.astro      HTML shell, SEO, JSON-LD, theme bootstrap, global widgets
  components/             One file per section or widget (markup, scoped CSS and its script together)
  pages/                  index, labs/index, labs/[slug] (35 lab pages), 404
scripts/
  sync-labs.mjs           Lab repos to Astro content, with curated names and tags
  sync-github.mjs         GitHub contributions and repo stats to src/data/github.json
```

## Home page sections

| Section | Component | Inspiration | Notes |
| --- | --- | --- | --- |
| Hero | `Hero.astro` | codesval tunnel | Flies through 18 real lab topologies. Cards fade where they would sit behind the copy. Off on screens under 520px tall and with reduced motion. |
| About | `About.astro` |  | Portrait, facts and grouped toolbox. |
| Selected work | `FeaturedStack.astro` | ujjwal stacking projects | Sticky cards that scale and dim as the next arrives. No sticky on screens under 620px tall. |
| Lab library | `LabLibrary.astro`, `LabRows.astro` | codesval folders, shafisma rows | Glass folders act as tabs; rows fill on hover with a trailing topology preview and a tick sound. |
| Process | `Process.astro` | codesval process | Wave path draws on scroll with a packet on the leading edge. Pinned on desktop, vertical rail on phones. |
| Credentials | `Credentials.astro` |  | Bento of the four real certificates; opens in the shared lightbox. |
| Experience | `Experience.astro` | parthh timeline | Rail fills with scroll; the portrait travels as the marker. |
| Terminal | `Terminal.astro`, `scripts/terminal.ts` | old portfolio CLI | Portfolio shell: help, about, skills, ls/cd/cat over labs and certs, open <lab>, cv, contact, theme, sudo hire. Tab completion, history, typo hints, clickable output. |

| Contact and footer | `Contact.astro`, `Footer.astro` | codesval footer | Beam-lit panel and a giant wordmark. |

Global widgets: `Nav.astro` (scroll-spy pill, mobile menu, theme and sound toggles), `Cursor.astro` (fine pointers only), `DotField.astro` (dotted topology canvas that links dots to the pointer and pings on click), `CommandMenu.astro` (Ctrl K or / to search labs), `Lightbox.astro`.

## Rules the code follows

- Accent, neutrals and shapes come only from tokens. Interactive controls are pills, containers 20px, media 12px.
- Every animation honours `prefers-reduced-motion`. Pinned and sticky effects switch off on short screens.
- No scroll listeners drive animation; ScrollTrigger and IntersectionObserver do.
- Touch devices get native scrolling, no custom cursor, no hover previews.
- Copy follows the claim policy: lab work is described as lab work. No em-dashes anywhere.

## Changing common things

| Want to | Edit |
| --- | --- |
| Change the accent colour | `--accent`, `--accent-rgb`, `--accent-text` in `tokens.css` (both themes) |
| Rewrite a headline or fact | `src/data/site.ts` or the section component |
| Add a certificate | Add the image to `src/assets/certs/`, then an entry in `credentials` in `site.ts` |
| Add an experience entry | `experience` in `site.ts` |
| Feature a different lab | Set `featured` in the `CURATED` map in `sync-labs.mjs`, add copy to `featured` in `site.ts`, run `npm run sync:labs` |
| Add a new lab | Push it to its repo folder locally, add a `CURATED` entry, run `npm run sync:labs` |
| Slow the tunnel or change its depth | `motion.tunnel` in `src/config/motion.ts` |
